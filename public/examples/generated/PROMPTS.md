# Generated example prompts

All 12 examples were created with the built-in OpenAI `image_gen` tool. No web images, remote
hotlinks, real brands, protected characters, personal data, or official Roblox UI captures are
used. The production files are 1600 × 1600 WebP; `-800.webp` files are responsive derivatives.

The prompts below are the final prompt set used for the shipped assets. Assets 04 and 06 use a
second edit prompt to preserve a paired comparison.
